Recording, storage, notes, collections, chapters, Key Moments and Knowledge Cards run entirely in your browser (localStorage + IndexedDB). Transcription and Ask VoiceVault call this deployment's own /api/* routes, backed by Groq's hosted open-source Whisper and GPT-OSS models — they need GROQ_API_KEY and a connected Blob store to work. You'll see a real error, never a fake result, if those aren't set up.
